# 教学全链路智能工作台（教师 / 教研）

依据微信公众号文章 **《从备课到评课，20个WorkBuddy场景帮你搞定教学全链路【附提示词】》** 整理构建的教师与教研 AI 工作台。

## 功能

- **六大维度**：赛（评比备赛）、训（精准培训）、教（课堂教学）、研（教研活动）、评（教学评价）、管（队伍管理），共 20 个 AI 场景
- **🤖 AI 智能对话（内置大模型直连）**：在页面里直接连接任意 OpenAI 兼容接口（DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI / 本地 Ollama），流式对话、上传材料直接处理
- **材料上传**：支持 Word（.docx）、PPT（.pptx）、Excel（.xlsx）文档自动解析成文本，以及 .txt/.md/.json/.csv 等文本文件（Office 解析基于本地 JSZip，无需联网）
- **场景一键装载**：场景详情点「用此场景开始 AI 对话」，AI 立即扮演对应角色（磨课顾问、学情分析助手等），粘贴材料即可开工
- **双视角切换**：👩‍🏫 教师视角（12 个场景）/ 🔬 教研视角（10 个场景）/ 全部
- **场景卡片**：适合谁、能干什么、所需材料、完整提示词，一键复制即用
- **搜索**：按场景名称、提示词关键词、材料等实时过滤
- **收藏夹**：本地保存（localStorage），方便常用场景快速直达
- **最近使用**：自动记录最近打开的 10 个场景
- **导出**：一键导出全部 20 个提示词为 Markdown 文件
- 每个场景内置**使用边界提醒**（AI 输出仅供参考、需人工审核、保护隐私等）

## 目录结构

```
├── index.html        # 入口页面
├── css/style.css     # 样式
├── js/data.js        # 20 个场景数据（标题 / 维度 / 视角 / 提示词 / 边界）

```

## 使用方式

纯静态页面，无需构建：

1. 直接双击打开 `index.html`；
2. 或启动本地静态服务预览（推荐，剪贴板 API 更稳定）：

```bash
# 方式一：Python
python -m http.server 8000
# 浏览器访问 http://localhost:8000

# 方式二：Node
npx serve .
```

## 使用方法（三步）

1. **选场景**：按维度浏览或搜索，找到想省时间的任务；
2. **复制提示词**：打开场景详情，一键复制提示词；
3. **发给 AI**：粘贴到 WorkBuddy / DeepSeek / 文心一言 等对话式 AI，附上材料（教案、成绩表、课堂实录转写等）按提示词对话即可。

> ⚠️ 所有场景的 AI 输出仅供参考，关键结论请结合实际情况人工审核；注意保护学生与教师隐私，不做横向排名、不贴负面标签。

## 连接大模型（内置 AI 对话）

1. 打开页面 → 点击左侧 **🤖 AI 智能对话** → 右上角 **⚙️ 模型设置**；
2. 快捷选择服务商（DeepSeek 官方 / 通义千问 / Kimi / 智谱 / OpenAI / Ollama 本地），填入 API Key 与模型名称，点 **🔌 测试连接** 验证，再 **💾 保存并连接**；
3. 回到对话区直接输入，或 📎 上传教案 / 成绩表 / 课堂实录等文本材料让 AI 处理；
4. 更省事：打开任意场景卡片 → **「用此场景开始 AI 对话」**，AI 直接进入该角色。

> ⚠️ API Key 仅保存在本机浏览器 localStorage。若浏览器跨域（CORS）被拦截，可改用 **Ollama 本地模型**（免费、无需 Key），或自建 OpenAI 兼容网关（one-api / new-api）。
